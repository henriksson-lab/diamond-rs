Snapshots generated by pinned upstream DIAMOND 2.1.24 (baseline commit
`1d162b4fefb5e6b4d868c24e6ad551cad2dcf246`) on 2026-11-06. Build the reference
with upstream `makedb --in reference.faa -d db -p1`. Run `blastp -q query.faa`
or `blastx -q query.fna`, with `-d db -p1 --masking MASK --comp-based-stats CBS`
and the output fields in `tests/native_seg.rs`.

The synthetic sequences test algorithm boundaries, not performance. The mixed
protein contains an internal 45-alanine interval between complex anchors;
the control is complex, and the final target is entirely low-complexity.
The DNA query encodes the same mixed protein. Snapshots cover SEG and masking
disabled, both with/without Hauser composition correction. They preserve
upstream's alignment choices through the masked interval, including the
gap-heavy CBS-enabled result. Native tests build their own database and check
both in-memory and forced-disk searches without C++ sources or FFI.

The corresponding `.daa` snapshots additionally check exact wire bytes, not
only decoded alignments. Upstream stores each match cell as a count-1 operation
and reverses insertion count chunks during backward traceback. Its unused
`Config::reward`/`penalty` fields are not initialized by its parser; the pinned
comparison executable writes zero in both DAA header slots. Rust deliberately
writes deterministic zeroes for these unused protein/translated fields rather
than reproducing arbitrary stack contents or substituting the unrelated
`match_reward`/`mismatch_penalty` defaults.
